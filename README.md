## 我是谁？
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;本人所学所想比较杂，但是为了解释这套理论是怎么来的，以及找到一些可能可以共鸣的朋友，我准备把我的思考历程分享出来。<br>
首先，本人是医学硕士，方向是医学建模。我做了很多年临床和研究工作，在工作中我意识到人体是一个分层级、且每一层级都有极多变量交互的复杂系统，比如把人体比作一个整体，首先是由各个系统（如呼吸系统，消化系统等）维持人体各项功能，每个系统又是由各器官组成，器官由又组织构成...这样的思维方式，一直可以细分到分子层面的相互交互作用。而这一个完整的体系，每天都在进行着大量的信息交互（周期性的和非周期性的），由于组成这个系统的因素足够复杂且庞大，环环相扣，相互制约，使得整个系统存在了一个相对稳定的动态平衡，正因为有这样一个动态平衡的存在，人体在面对各种外源性刺激和干预时候，就可以进行一定程度的抵御和代偿。而当动态平衡被打破时，则需要外界干预（治疗）对引起平衡失衡的因素进行修复，以修正平衡，如果修正不回来，整个系统就会往一个方向进行动态演化（比如病态或者死亡），而如果对这个系统足够了解时，我们是可以推测出演化方向的（就像医生可以告诉患者，再过几年，大概怎样怎样...）。这个“复杂系统”的概念一直是我做医学研究工作的指导思想，为此我设计了不少的医学研究并取得了一些成果，这更使我坚信“复杂系统”的认识的可靠性。其实不止是人体和医学，往大了说，宇宙，地球生态，社会...往小了说，微观生态，细胞等等，都可以通过“复杂系统”的思考方式去拆解，其本质就是大量的，不同层面的因子的相互影响所构成的相对稳态，具有常态时的稳定性和非常态时的定向演化性，这是我一个基本的认知前提。<br>
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;其次，在一些机缘巧合下，我接触并掌握了命理。这可能不符合很多人从小接受的世界观，但是其实命运是客观存在的，就像我们小时候总被教育小朋友都是一样聪明，努力就可以有所收获。但是随着我们长大，慢慢发现这是一句谎言，客观事实是，人的智力水平是有差距的，努力也不一定有所收获。命运的存在具有客观性这件事情虽然乍一听不符合科学性，不像是我这样的教育背景的人说出来的话，我们应该是笃信因果关系，讲逻辑的。但是当下不妨让我们抛开唯物主义那套视角，去回忆自己的人生中的某一个事件（各位可以试试），我们会发现很多对我们人生方向有很大影响的事件，通过因果关系抽丝剥茧到最初，可能只是我们没来由的一个念头，而这个念头，你以为是你那时候的主观所思，其实是运在你内心的投射，其实绝大多数事情的源头就是念，先是一个没来由的起心动念，才会有接下来的事情，而这个念，换做别人就不会有，在你身上，即使换个时间点，也不会有，具有不可重复性，但是又影响了人生的方向，这就是运。这时候有人可能会说，那我就是这样一个人啊，有这个念头是因为我的人的特殊性在这个时间点和场景下的体现，但事实上，我们的性格、智力水平、思维方式、价值取向、身体状况等“初始属性”，都是被天地间的一套系统设定好的（一开始我也难以置信，不过各位随便找一个懂行的师傅去看一眼就知道，可以把你性格说的清清楚楚，只是这行当骗子太多了），这个叫做命（原局），我们在不同人生阶段的念头以及因这个念头而发生的一系列蝴蝶效应般的事情，叫做运。包括我现在决定把钱与道这套体系公开，也是基于一种寻找同类的念头，想找到一些有共鸣的朋友。那为啥这套命运系统能够存在呢？有没有什么客观依据？在本人研究了东方和西方两种命理体系后，有一个答案——命运本身就是星体运转时带来的能量对你的影响。可以理解为太阳系是一个巨大的服务器，里面的星体的运转给天地间带来了能量（姑且叫能量吧，其实就是我们常说的金木水火土），这个影响有两个方面，在你出生的那一瞬间，你接收到的天地间的能量，就构成了你的原局，也就是你的基本属性，然后天地能量继续运转，其他能量对你原局的影响，就是你的运。为啥我有这样的解释呢？因为我研究了东方命理学和西方命理学的起源，发现都是从观察星星开始的，只是东方的智者们慢慢把这些星星的能量符号化了（比如八字里的五行，紫微斗数的星耀等），而西方命理学则把星保留了下来。演化成了占星术，但是两者的本质都是天体运动对于个人的影响。那有人可能会问，为啥天体运动会对个人产生影响呢？这个就不好说了...有很多种猜想，比如地球是一个巨大的监狱，天体是高维存在用来锁住人类智慧演化的。或者世界是虚拟的，天体运动及其影响就是底层代码之一。Whatever，这不是我们讨论的重点，也无法证实或证伪。之所以啰嗦这么多命理学的东西，纯粹是后面为了讲“道”的存在以及“运”对交易的影响。<br>
（金融，方向性研究。）
